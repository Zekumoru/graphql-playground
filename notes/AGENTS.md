# Topic notes

- Use this shared folder for requested explanations of interesting topics. Create a Markdown file for each topic directly in this folder rather than a topic subfolder containing a README.
- Name new notes `YYYYMMDD-topic-name.md`, using the creation date in the user's timezone and a short kebab-case topic name, for example `20260911-lists-and-nullability.md`. Preserve the date prefix when updating an existing note.
- Write durable explanations, not temporary task state. Favor concrete examples that make differences obvious; for GraphQL behavior, show the schema, query, and resulting response together for each case, emphasizing what changes.
